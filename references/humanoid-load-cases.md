# Humanoid load cases

Select candidates from intended activities: double-leg standing, single-leg stance, toe-off, heel strike, maximum joint acceleration, squat/lift, payload at reach, stair ascent, trip recovery, emergency stop, actuator stall, forward/backward/lateral fall, transport/handling, maintenance, and motor/battery/electronics thermal loading.

For every selected case record:

- source and provenance of magnitude;
- coordinate frame and direction;
- magnitude, distribution, time basis, and combination rule;
- supports, remote points, contacts, friction, preload, and separation behavior;
- uncertainty and dynamic/impact multiplier;
- applicable failure modes, margin targets, outputs, and acceptance criteria.

Prefer measured data, actuator limits, multibody simulation, or test specifications. A proposed conservative assumption requires approval. Never use an arbitrary fixed support merely because it makes the model solvable.
