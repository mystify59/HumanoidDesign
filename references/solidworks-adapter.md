# SOLIDWORKS adapter

Discover live tools and confirm the Windows session, document type, absolute path, active configuration, units, save state, and modal-dialog state.

Map capabilities to parts, assemblies, sketches, features, mates, reference geometry, stable entity IDs, mass properties, interference/clearance, drawings, and neutral exports. Prefer declarative plans or transactions, stable IDs, explicit merge/cut scope, and checkpoints.

Only the server should touch the COM API. Stop for unknown modal dialogs or ambiguous selections. After mutation verify topology, body/component counts, configuration, axes/mates, bounding boxes, volume/mass, and an independent export or readable artifact.
