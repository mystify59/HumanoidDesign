# Ansys Mechanical adapter

Discover live tools. Confirm launch/attachment, Mechanical instance, project and analysis identity, geometry revision, units, named selections, and connection mode.

Map capabilities to geometry inspection, materials, contacts, joints, mesh controls/statistics, loads/supports, solver controls, solution status, results, plots, and exports. PyMechanical MCP implementations may use a persistent remote gRPC session; never assume a particular port or tool name.

Native scripting is high privilege and requires approval plus review of the exact script. Before solving, show analysis type, assumptions, materials, connections, loads, mesh/convergence criteria, margins, requested outputs, runtime/cost, and checkpoint. After solving inspect warnings, residuals, convergence, balance, singularities, sensitivity, and requirement comparisons.
