# Reporting

## Preflight

Report objective, source artifacts/revisions, application/MCP versions, active document/configuration, consequence, selected and recommended fidelity, mismatch acknowledgement, assurance profile, requirements, assumptions, failure-mode margins, operations, load cases, solver/mesh settings, expected cost, checkpoint, evidence, stop conditions, and the exact approval requested.

## Result report

Report approved scope, operations actually performed, artifacts created, checkpoints, boundary conditions, materials, contacts, mesh and solver settings, warnings/convergence, independent verification, results per criterion, assumptions, uncertainty, and next actions.

Use only `pass`, `conditional_pass`, `fail`, or `inconclusive` per criterion. Separate native solver output from engineering interpretation. State when fidelity restricts the conclusion. Never equate a pass with certification or overall robot safety.
